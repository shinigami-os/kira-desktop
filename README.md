# kira-desktop
> Desktop environment configuration for Kira Linux.

Ships an opinionated, minimal Wayland desktop based on SwayFX. Every config file is documented and meant to be read and modified.

## Components
| Component | Role |
|---|---|
| SwayFX | Compositor (primary) |
| Waybar | Status bar |
| Wofi | Application launcher |
| Mako | Notifications |
| swaybg | Wallpaper |
| swaylock-effects | Lock screen |
| Flameshot | Screenshots |

Sleex is supported as an alternative desktop environment, available via `flux install sleex`.

## Status
Pre-development. See the [Kira Linux specification](https://github.com/shinigami-os) and the project roadmap.
